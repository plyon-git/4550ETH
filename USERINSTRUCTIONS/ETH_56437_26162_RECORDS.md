# Frozen ETH records: +564.37% and +261.62%

Project-specific owner: Parrish Lyon.

The [published record folders](../published_eth_records/README.md) preserve the exact two five-year ETH diagnostics. Each folder is labeled with cumulative gain, date range, net win rate and initial RR. The publication includes all market-input bytes as checksum-verified parts, original training/execution source, fitted model weights, every timestamped trade and all period returns.

From `published_eth_records/` using Python 3.13:

```sh
python -m pip install -r shared/frozen_v8/requirements.txt
python reproduce.py --case both --verify-models --retrain --minute-equity
```

This assembles the local raw input without downloading anything, reconstructs the original features, retrains and checks all model folds, and reruns both historical accounts. It never submits orders. The first installation requires package access; later reruns are offline with installed dependencies.

The complete data is directly in Git, not an expiring artifact dependency. The downloadable release is also self-contained. Original strategy records and the V4 live service remain unchanged. Cumulative gains are not annual gains; fee, risk, drawdown, collateral and hindsight-selection assumptions remain recorded. No new broker integration or live activation is represented by this publication.
